## سوابق شغلی

### توسعه‌دهنده ارشد فلاتر — پلتفرم و معماری
**شرکت توسعه و نوآوری زرپران هوشمند** *(هلدینگ آریا فاتح خاورمیانه — محصول Minerva ERP)*  
تهران · دی ۱۴۰۴ – اکنون

- تولید کدهای زیرساختی و پلتفرمی برای داشبورد ERP سازمانی Minerva در سطح هلدینگ.
- طراحی و پیاده‌سازی فریم‌ورک پایه داخلی Flutter و اسکلت پروژه برای معماری یکپارچه تیم‌ها.
- پیاده‌سازی Clean Architecture به‌صورت feature-first و جداسازی لایه‌ها (domain / data / application / presentation).
- جداسازی DI از state مدیریت‌شده در UI (`get_it` + `injectable` برای DI و Riverpod برای state) و مستندسازی تصمیم‌ها با RFC/ADR.
- راه‌اندازی ساختار چندمحیطی (dev / stage / prod)، الگوی مسیریابی با go_router و زیرساخت شبکه مبتنی بر Dio.
